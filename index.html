เชื่อมต่อฐานข้อมูล Google Sheets

บันทึกข้อมูลทุกรายการลงใน Google Sheets ของคุณในชีต "return ricoh" เป็น Database อัตโนมัติในทุกเครื่องที่เปิดใช้งาน

นำ URL จากการ Deploy Web App ใน Google Sheets มาวางที่นี่

วิธีติดตั้งระบบ Database ใน Google Sheets (ทำครั้งเดียว):

  1. เปิด Google Sheets ของคุณ หรือ คลิกเปิดตรงนี้
  2. ไปที่เมนู ส่วนขยาย (Extensions) > Apps Script
  3. ลบโค้ดเดิมใน Code.gs ออกทั้งหมด แล้วกดวาง (Paste / Ctrl+V) โค้ดที่คัดลอกมา จากนั้นกดบันทึก
  4. กดปุ่มสีน้ำเงิน ทำให้ใช้งานได้ (Deploy) > การทำให้ใช้งานได้ใหม่ (New deployment)
  5. เลือกประเภท เว็บแอป (Web app) และตั้งค่า ผู้ที่มีสิทธิ์เข้าถึง: ทุกคน (Anyone)
  6. กด Deploy แล้วคัดลอก Web App URL มาวางในช่องด้านบน แล้วกดบันทึก
